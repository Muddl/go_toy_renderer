## Technical Notes

- OBJ loader: stdlib `bufio.Scanner` line-by-line; no external parser library
- UV coordinates require a 4th vertex attribute (float32×2); vertex stride grows to 44 bytes
- Staging buffer pattern for texture upload: `wgpu.BufferUsage_CopySrc` → `CopyBufferToTexture`
- GPU timestamp queries: `wgpu.QueryType_Timestamp`; resolve to buffer after frame
