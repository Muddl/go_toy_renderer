# Specification: Phase 12 — GPU Geometry & Draw Pipeline

**Track ID:** phase-12-gpu-geometry_20260227
**Type:** Feature
**Status:** Pending
**Created:** 2026-02-27

## Summary

Upload scene geometry into GPU vertex and index buffers (VRAM) and replace the hello triangle with hardware-rasterized draws of actual `pkg/geometry.Mesh` data.

## Context

Phase 12 connects the existing CPU mesh data model to the GPU pipeline. Vertex data from `pkg/geometry.Mesh` is packed into a `wgpu.Buffer` (VRAM), and indexed draw calls replace the placeholder hello triangle from Phase 11. The CPU rasterizer is no longer used in the GPU path.

## User Story

As a developer, I want the GPU backend to render the same coloured cube as the CPU renderer using hardware rasterization, so I can verify geometry upload and indexed drawing.

## Acceptance Criteria

- [x] `pkg/gpu` gains `VertexBuffer` and `IndexBuffer` helpers that upload `[]geometry.Vertex` and `[]uint32` to VRAM via `wgpu.Device.CreateBuffer`
- [x] Vertex layout matches shader input: position (float32×3) + colour (float32×3), stride 24 bytes
- [x] `GPUBackend.RenderFrame` performs: geometry upload (or re-use cached buffers) → `setVertexBuffer` + `setIndexBuffer` → `drawIndexed`
- [x] The coloured cube from `geometry.NewCube()` renders correctly (correct perspective, depth ordering)
- [x] MVP transform applied in vertex shader (hardcoded camera for now; uniforms in Phase 14)
- [x] Depth buffer (`wgpu.TextureFormat_Depth24Plus`) created and bound to render pass
- [x] Frame rate still ≥60 fps at 1280×720

## Dependencies

- Phase 11 (wgpu-native swapchain + render pass)
- `pkg/geometry` — existing Mesh type

## Out of Scope

- Standalone WGSL shader files (Phase 13); use hardcoded inline WGSL for this phase
- Per-mesh transform uniforms (Phase 14)
- Multi-mesh scenes (Phase 14)

## Technical Notes

- Buffer creation: `wgpu.BufferUsage_Vertex | wgpu.BufferUsage_CopyDst`
- Pack vertices as `[]float32` before upload (match WGSL struct layout)
- Depth texture must be recreated on window resize (future work)
