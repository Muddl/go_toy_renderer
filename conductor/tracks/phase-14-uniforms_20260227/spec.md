# Specification: Phase 14 — Uniform Buffers & Per-Mesh Transforms

**Track ID:** phase-14-uniforms_20260227
**Type:** Feature
**Status:** Pending
**Created:** 2026-02-27

## Summary

Introduce GPU uniform buffers carrying the camera view-projection matrix and a per-mesh model matrix, enabling multi-mesh scenes where each object has an independent transform.

## Context

Phase 13 hardcodes the MVP matrix in the vertex shader. Phase 14 externalises it via a `wgpu.BindGroup` containing a uniform buffer. A new `pkg/scene` package provides a `Transform` component for per-mesh positioning, replacing the flat mesh list in `pkg/render.Scene`.

## User Story

As a developer, I want to render multiple meshes with independent positions, rotations, and scales so I can build more complex scenes and verify the camera and transform pipeline end-to-end on the GPU.

## Acceptance Criteria

- [ ] `pkg/scene` package: `Transform` struct (position Vec3, rotation Vec3 Euler, scale Vec3), `Node` struct (mesh + transform), `Scene` struct (nodes + camera)
- [ ] Uniform buffer layout: `CameraUniforms` (viewProj Mat4x4, 64 bytes) + `MeshUniforms` (model Mat4x4, 64 bytes)
- [ ] `GPUBackend` creates a bind group layout and bind groups for camera + per-mesh uniforms
- [ ] Camera uniform updated once per frame; mesh uniform updated per draw call
- [ ] Vertex shader in WGSL reads camera and mesh uniforms via `@group`/`@binding` decorators
- [ ] Demo scene in `cmd/renderer-rt`: cube + tetrahedron at different positions; both rendered correctly
- [ ] All existing tests still pass: `go test ./...`

## Dependencies

- Phase 13 (WGSL shader pipeline)
- `pkg/math` Mat4x4 for model matrix construction

## Out of Scope

- Normal matrices (Phase 15)
- Material/texture uniforms (Phase 16)
- Instance buffers (future)

## Technical Notes

- Uniform buffer alignment: WebGPU requires 16-byte alignment for uniform structs
- `pkg/scene` replaces `pkg/render.Scene` for GPU path; CPU renderer keeps `pkg/render.Scene`
- Per-mesh push constants would be simpler but WebGPU does not support push constants; use dynamic offsets or separate bind groups
