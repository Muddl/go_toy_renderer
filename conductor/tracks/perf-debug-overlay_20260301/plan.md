## Overview

Build the overlay bottom-up: start with pure-Go data types and text
rendering (fully testable in headless CI), then wire compositing into the
CPU framebuffer path, then add the wgpu second-pass overlay for the GPU
backend. The F3 key callback and frame timing instrumentation are added
during each backend's integration step.
